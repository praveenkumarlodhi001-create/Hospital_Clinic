# NOVACARE — Hospital / Clinic Website Demo

Premium, futuristic and responsive clinic website built using plain HTML, CSS and JavaScript. No framework or build step required.

## Preview
Extract the ZIP and open `index.html` in Chrome or another modern browser. Google Fonts and Unsplash images require internet access.

## Included
- Responsive healthcare landing page with animated hero, orbit motif and marquee
- Service / specialty cards and clinician profile showcase
- Scroll reveal animations and reduced-motion support
- Interactive testimonial slider
- Appointment request form with required-field validation and date restriction
- Responsive mobile navigation
- Contact details, emergency support banner and clear demo notices

## Important before client delivery
NOVACARE, its clinicians, contact details, experience figures, services, testimonials and address are fictional sample content. Replace them with verified clinic information and obtain permission for all photos and clinician details. This is a front-end demonstration only: appointment submissions are not transmitted or stored, and it is not an emergency service. Integrate a secure backend, privacy-compliant patient workflow and real contact channels before production. Do not collect real patient or medical information through this demo form.
